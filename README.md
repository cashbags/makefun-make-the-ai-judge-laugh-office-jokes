**Make the AI Judge Laugh: Office Jokes** — one line about office life:

> Our office plant died, so facilities replaced it with a poster of a plant.

## The joke

The setup is a dead office plant; the fix is facilities replacing it with a
poster of a plant. One real office pain — the performative cheap fix that
costs nothing and changes nothing — twisted once, deadpan, with no second
sentence to explain it. 74 Unicode code points, one line.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# writes out/entry.txt — byte-identical on every run
```

`main.ts` (Node 22, stdlib only) holds the joke as one constant, checks it
against the competition's own gate first — 1–199 Unicode code points,
a single line, not only whitespace — and writes it to
`/output/entry.txt`. No clock, no random source, no network, so two runs
write identical bytes.
